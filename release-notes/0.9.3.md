# VoiceHotkey 0.9.3 — 安装包已撤下 / Installer withdrawn

> **0.9.3 安装包已撤下，当前页面不再提供下载。** 请使用 [最新版本](https://github.com/yeahhe365/VoiceHotkey-releases/releases/latest)，并查看该版本的系统要求、安装与授权说明。

## 历史版本信息

- 原 0.9.3 安装包适用于 **Apple Silicon（arm64）Mac，macOS 14 或更高版本**；该安装包不包含 Intel（x86_64）主程序。
- 此版本尚未经过 Apple 公证，也未使用 Apple Developer ID 签名。
- 语音输入需要麦克风与辅助功能权限；使用 Apple 系统语音时还需语音识别权限。

## 安装与首次启动

请下载当前 [最新版本](https://github.com/yeahhe365/VoiceHotkey-releases/releases/latest)，将 VoiceHotkey.app 拖到应用程序目录，从固定安装路径启动，并完成权限引导。

若 macOS 无法验证当前下载版本，先确认官方来源与校验和，再按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)处理。若提示文件损坏，请核对校验和并重新下载；仍有问题请联系支持。清除隔离属性不等于验证文件完整性或完成 Apple 公证。

## English summary

The 0.9.3 installer has been withdrawn and is no longer available on this page. Use the [latest release](https://github.com/yeahhe365/VoiceHotkey-releases/releases/latest).

The historical installer was arm64 only, for Apple Silicon Macs running macOS 14 or later; it did not contain an Intel executable. It was not notarized or signed with Apple Developer ID. Voice typing needs Microphone and Accessibility; Apple Speech also needs Speech Recognition permission.

For the current release, verify its source and checksum and follow [Apple's opening guidance](https://support.apple.com/en-us/102445) when applicable. A damaged-file warning should prompt a checksum check, a fresh download, and support if unresolved.
