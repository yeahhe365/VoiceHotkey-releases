# VoiceHotkey 0.9.4

## 授权与设置更新

- 首次激活和更换激活码需要联网，服务器确认后才启用 Pro。
- 激活和联网验证成功后，可离线使用 Pro 最长 30 天；到期后在「设置 → 许可证」中点击「验证许可证」。
- 已激活用户升级后需联网验证一次。沿用原激活码，每个许可证最多绑定 3 台 Mac。
- 授权凭证绑定当前激活码和 Mac，并由服务器签名。服务不可用或断网时不会自动延长有效期。
- 增加「验证许可证」入口和离线有效期说明。
- 精简输入模型页面；恢复完整文件拖放区域，将文件转写选项放在任务列表上方。

## 系统要求与安装

- 此安装包适用于 **Apple Silicon（arm64）Mac，macOS 14 或更高版本**。
- 下载 `VoiceHotkey-0.9.4.dmg`，将 VoiceHotkey.app 拖到「应用程序」后启动。
- **此版本尚未经过 Apple 公证，也未使用 Apple Developer ID 签名。** macOS 可能阻止首次打开。核对官方来源后，可按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)在「系统设置 → 隐私与安全性」中允许打开。
- 若提示文件损坏，请核对校验和并重新下载；仍有问题请联系支持。
- 按提示授予麦克风与辅助功能权限；默认 Apple 系统语音还需授予「语音识别」权限。已有用户的权限可能需要重新确认。

## English summary

First activation and key changes now require an online confirmation. Pro access uses a server-signed, device-bound receipt valid for up to 30 days offline. Existing users need one online verification after upgrading; their existing key and three-Mac limit remain applicable.

This installer supports Apple Silicon Macs running macOS 14 or later. It has not been notarized or signed with Apple Developer ID. Review [Apple's opening guidance](https://support.apple.com/en-us/102445) if macOS blocks it. Grant Microphone and Accessibility; the default Apple Speech engine also requires Speech Recognition permission.
